# Local Audio Directory

Place your legally obtained, licensed audio file for the wedding invitation here:

- **Filename**: `love-story.mp3`
- **Location**: `/public/audio/love-story.mp3`

### Requirements
- Format: MP3 (recommended bitrate: 128kbps - 320kbps)
- Song: *Love Story* by Taylor Swift (*Fearless*)
- The music player in the invitation will automatically detect this file and enable playback with play/pause and volume controls.
- When this file is absent, the player displays a clear "Audio file awaiting placement" status.
